# OfficePilot – Pilot-Betriebspaket

Begleiteter Pilot für den ersten realen Betriebseinsatz.

| | |
|---|---|
| **Dauer** | 3 Wochen (Minimum 2, Maximum 4) |
| **Ziel** | Kernabläufe lokal im Browser prüfen: Dokumente, Vorgänge, Rechnungen, Backup |
| **Technik** | Ein Gerät, ein Browserprofil; Daten lokal; ZIP-Datensicherung |

Produktgrenzen und Hinweise stehen **in der App**, nicht in diesem Ordner doppelt:

- Firmendaten → **Hinweise zum Pilotbetrieb**
- Firmendaten → **Datensicherung** → `/firmendaten#datensicherung`
