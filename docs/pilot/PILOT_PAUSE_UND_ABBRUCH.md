# Pause- und Abbruchregeln

**Kennzeichnung:** überwiegend **nur intern**; Kurzfassung unten für den Betrieb.

## Für den Betrieb (Kurz)

| Regel | Aktion |
|-------|--------|
| Persistenzbanner bleibt sichtbar | Arbeit **pausieren**, ZIP sichern, Begleitung melden |
| Verdacht auf Datenverlust oder Restore-Fehler | Sofort **pausieren**, Begleitung holen |
| Anderes Gerät / anderes Browserprofil | **Nicht** unkontrolliert wechseln |
| Echter Versand / Buchhaltung | Immer über **Altsystem** |

Produktiver Restore nur **gemeinsam mit Begleitung**.

## Nur intern – Pause

| Auslöser | Maßnahme |
|----------|----------|
| Dauerhaftes Persistenzbanner | Pilot pausieren; Speicher/Quota klären; Backup prüfen |
| Restore fehlgeschlagen oder Datenverlustverdacht | Pause; Safety-ZIP / letzte bekannte Sicherung; kein Weiterarbeiten im unsicheren Stand |
| Unkontrollierter Geräte-/Browserwechsel | Sofort stoppen; auf vereinbartes Profil zurück; Datenlage klären |

## Nur intern – Abbruch

| Auslöser | Maßnahme |
|----------|----------|
| Wiederholter Datenverlust trotz Begleitung | Pilot **abbrechen** |
| Cloud-Sync / E-Rechnung / Auto-Versand werden Geschäftsgrundlage | Erwartung klären oder Pilot stoppen |
| Betrieb kann Ein-Gerät-/Backup-Regel nicht einhalten | Stopp oder stark verkürzter begleiteter Modus |

## Führende Systeme

- **Altsystem** bleibt für Kundenversand und Buchhaltung führend bis Pilotende.  
- OfficePilot ist im Pilot **begleitetes** Werkzeug, kein Ersatz ohne Absprache.
