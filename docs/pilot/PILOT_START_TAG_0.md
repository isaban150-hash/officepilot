# Pilot-Startcheckliste – Tag 0

**Zielgruppe:** Betrieb + Begleitung  
**Zeit:** ca. 60–90 Minuten vor dem ersten Arbeitstag

Produkttexte nicht hier pflegen — Grenzen und Backup in der App prüfen:

- Firmendaten → Hinweise zum Pilotbetrieb  
- Firmendaten → Datensicherung → `/firmendaten#datensicherung`

## Checkliste

| # | Schritt | Erledigt |
|---|---------|----------|
| 1 | **Ein Gerät** und **ein festes Browserprofil** (z. B. Chrome/Edge) vereinbart; kein Parallelbetrieb in anderem Profil | ☐ |
| 2 | Login möglich | ☐ |
| 3 | Benutzer **freigeschaltet** (nicht mehr „wartet auf Freigabe“) | ☐ |
| 4 | **Lizenz** aktiv (App erreichbar, kein Lizenz-Hinweis) | ☐ |
| 5 | **Firmeneinrichtung** abgeschlossen | ☐ |
| 6 | **Firmendaten und Rechnungsangaben** geprüft (Name, Adresse, Steuer/Bank, Rechnungsnummer) | ☐ |
| 7 | Unter `/firmendaten#datensicherung` **erstes ZIP-Backup** heruntergeladen und an vereinbartem Ort abgelegt | ☐ |
| 8 | **Hinweise zum Pilotbetrieb** in Firmendaten gemeinsam gelesen und bestätigt | ☐ |
| 9 | **Ansprechpartner** und **Supportweg** notiert (Name, Kanal, Reaktionszeit) | ☐ |
| 10 | Klar: Altsystem bleibt für **echten Versand** und **Buchhaltung** führend | ☐ |
